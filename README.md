# COLORS-LAB

The COLORS application is a web browser that allows its users to add colors to a database and search for the colors within the database.

This site uses DigitalOcean to create a LAMP droplet and a GoDaddy domain to host the IP address. 

# Set up Instructions
1. Create a LAMP droplet through DigitalOcean
2. Get a domain name from a provider (ex. GoDaddy)
3. Clone this repository into your root: git clone https://github.com/Karmaxenn/COLORS-LAB
4. Create a database within the web console in the LAMP droplet
5. Copy the files from the repository into your files within the root of your LAMP droplet
6. Test the APIs using Postman at your URL
